Partnership models

Select the model that suits your organization

RECURRING

Revenue share

Receive 70% of all revenue generated from API requests and licences for the duration of the listing.

  • Non-exclusive arrangement
  • Real-time usage reporting
  • Suited to regularly updated datasets
ONE-TIME

Outright acquisition

Datum acquires a licence to your dataset for a fixed, upfront fee.

  • Payment upon delivery
  • No ongoing obligations
  • Suited to historical or static datasets
ON DEMAND

Commissioned collection

Datum engages you to collect or supply data in response to specific client requirements.

  • Fixed fee per engagement
  • Defined specification and timeline
  • Suited to domain and regional specialists
Integration options

Flexible integration methods

One-time files or live feeds. Setup support included.

REST API or webhook

Provide an endpoint for us to retrieve data from, or push records to our ingestion API in real time.

Cloud storage

Grant access to an Amazon S3, Google Cloud Storage or Azure Blob location. New files are synchronized automatically.

SFTP

Deliver scheduled files to a dedicated, encrypted SFTP directory.

File upload

Upload files in CSV, Excel, JSON or Parquet format. Recommended for one-time datasets.

Database connector

Provide read-only access to PostgreSQL, MySQL, Snowflake or BigQuery, or to a shared view.

Enterprise-grade security

Data is encrypted in transit and at rest, access follows least-privilege principles, and credentials can be revoked at any time.

Partner requirements

Our data quality and compliance standards

Every partner and dataset is reviewed before listing.

Review prohibited data types

Ownership or licensing rights

You own the data, or hold a licence that permits its redistribution.

Lawful collection

The data was collected with appropriate notices and consent, without breaching third-party terms or access controls.

Responsible handling of personal data

Personal data is anonymised or aggregated, or supported by documented consent that permits onward licensing.

Complete documentation

A schema, update schedule and description of the collection methodology are provided.
